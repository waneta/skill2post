# DECISIONS

## ADR-001

- 日期：2026-10-08
- 决策：采用“真实任务实践 → 可复现教程 → 用户反馈 → 辅助工具”的项目闭环。
- 背景：原始构想同时包含 AI 技能教程和创作工具，范围过宽，且无法证明工具需求真实存在。
- 方案比较：
  - 先建设通用 AI 工具平台：开发投入大，需求未经验证。
  - 只运营教程账号：成本较低，但难以沉淀产品能力。
  - 用内容验证需求后再开发工具：能同时积累案例、用户反馈和产品依据。
- 结论：选择第三种方案；首阶段先完成 7 个同系列真实案例，不开发完整 SaaS。
- 影响范围：内容选题、案例结构、工具立项、路线图和商业化顺序。

## ADR-002

- 日期：2026-10-08
- 用户约束：学习成本高，希望高频制作小红书图文或视频。
- 决策：将首发实践单位缩小为单动作测试，复用工具、素材结构和发布模板。
- 修正：撤回 task02 中完整商品宣传片工作流作为强制起点的建议。先做三个小实验检验成本，再考虑扩展到七篇。
- 当前建议：从日常照片创意改造切入；图文与操作录屏共用实验素材。
- 验证边界：题目吸引力和每篇 45～60 分钟预算均未验证，不代表市场排名或产量承诺。
- 详细方案：见 ../dev_docs/2026-10/task02_我该如何开始.md。
