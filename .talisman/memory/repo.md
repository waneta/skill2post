# repo memory

## 稳定结论

- Skill2Post 面向个人创作者和小团队，核心是 AI 实战与内容产品化。
- 项目闭环是“真实任务实践 → 可复现教程 → 用户反馈 → 辅助工具”。
- 内容是需求验证渠道，工具是验证结果。
- 首阶段目标是连续完成 7 个同系列真实案例。
- 用户优先考虑低学习成本与高频发布；先用三个单动作实验检验制作成本，再扩展系列。task02 的商品宣传片起步建议已撤回。
- 图文和操作录屏可复用同一实验；新主题和制作时间预算尚需实测。

## 常见坑

- 不要扩张为泛 AI 工具导航或提示词搬运仓库。
- 不要在需求验证前开发完整 SaaS。
- 不要把未经人工核查的批量自动发布作为核心能力。

## 约束共识

- 每个案例必须有明确用户、真实问题、最终产物和复现步骤。
- 工具立项前必须存在重复需求和可稳定执行的人工流程。
- 事实核查、质量判断和最终发布保留人工确认。
