# Skill2Post

> Learn a skill. Build something real. Turn it into a useful post.

Skill2Post 是一个面向个人创作者和小团队的 AI 实战与内容产品化项目。

我们从真实任务出发，用 AI 学习并完成一个可展示的作品，记录工具、步骤、提示词和失败过程，再将经验整理成可复现教程。只有经过真实案例和用户反馈验证的重复流程，才会进一步开发为创作辅助工具。

## 核心闭环

    真实问题 → 学习与实践 → 完成作品 → 沉淀教程
            → 发布与反馈 → 验证需求 → 开发工具

项目口号：

> 学会一项技能，完成一个作品，发布一篇教程。

## 当前方向

首阶段聚焦三类场景：

- AI 内容生产：选题、写作、图片、短视频和内容复用。
- AI 办公提效：资料整理、PPT、表格、会议记录和报告。
- AI 小工具与自动化：把重复工作转化为简单工作流或工具。

第一阶段的目标不是开发完整平台，而是连续完成 7 个同系列真实案例，建立统一的实践记录和教程模板，并通过反馈找到第一个值得产品化的问题。

## 项目原则

- 从用户问题出发，不追逐工具清单。
- 先完成真实项目，再编写教程。
- 同时记录成功步骤、失败尝试和适用边界。
- 教程必须尽可能可复现、可验证。
- 内容用于发现需求，工具用于解决已验证的需求。
- AI 负责辅助，人负责事实核查、质量判断和最终发布。

## 不做什么

- 不做大而全的 AI 工具导航站。
- 不批量生产未经实践验证的教程。
- 不在需求尚未验证前开发完整 SaaS。
- 不以无人值守批量发帖或绕过平台规则为目标。
- 不承诺爆款、收益或完全自动化运营。

## 路线图

- [ ] 完成 7 个同系列 AI 实战案例。
- [ ] 建立案例记录与教程模板。
- [ ] 发布并记录有效反馈。
- [ ] 从高频问题中验证第一个付费服务或数字产品。
- [ ] 将一个稳定工作流实现为最小创作辅助工具。
- [ ] 用真实使用数据决定后续扩展方向。
